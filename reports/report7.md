## 1. Цель этапа

Передать текстовое сообщение *"hello"* через PlutoSDR, принять его на втором устройстве, сохранить принятый сигнал и визуализировать созвездие BPSK/QPSK (визуализация пока реализована на Python).

## 2. Проделанная работа

### 2.1. Передача сообщения "hello"

В функции `generate_bits` вместо случайных битов теперь заложена строка `"hello"`:

- каждая буква кодируется 8 битами;
- одно сообщение занимает 40 бит;
- при буфере большей длины сообщение повторяется циклически.

```text
01101000 01100101 01101100 01101100 01101111
   h        e        l        l        o
```

На передающей стороне сообщение формируется корректно.

### 2.2. Модуляция

| Режим | Правило | `bit_count` |
|--------|---------|-------------|
| **BPSK** | 1 бит → 1 символ (±1 на I, Q = 0) | `symbol_count` |
| **QPSK** | 2 бита → 1 символ (±1, ±1) | `symbol_count * 2` |

Цепочка передачи (TX):

```text
"hello" → биты → BPSK/QPSK → rectangular(L) → int16 I/Q → writeStream
```

Параметр `L` - длительность символа в сэмплах (используется значение 10).

### 2.3. Приём

- Сырой поток записывается в `sdrX_rxdata.pcm` - для построения графиков принятого сигнала.
- Принятые отсчёты сохраняются в текстовый файл `qpsk_symbols.txt` - для графиков созвездий.

### 2.4. Визуализация

1. **Python** (`matplotlib`) - построение созвездия и I/Q по данным из `.txt`.
2. **ImGui + ImPlot** (`graphGUI.cpp`) - в одном окне отображаются:
   - I/Q во времени;
   - созвездие (QPSK/BPSK, работа начата).
