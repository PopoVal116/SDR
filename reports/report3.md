## 1. Adalm Pluto SDR & Timestamp

### 1. Цель работы

Ознакомиться с работой **ADALM-Pluto** через библиотеку **SoapySDR**, научиться принимать и передавать IQ-сэмплы с использованием аппаратных временных меток (**timestamp**), а также получить и визуализировать принятый сигнал.

В ходе работы необходимо было:

- подключить PlutoSDR к аудиторному компьютеру под Linux;
- настроить параметры приёма и передачи (частота, sample rate, gain);
- реализовать одновременный RX/TX с привязкой к timestamp;
- принять сигнал, сохранить сэмплы и построить график I/Q составляющих.

---

### 2. Используемое оборудование и ПО

- SDR-устройство **ADALM-Pluto**
- Аудиторный компьютер (Linux)
- Библиотека **SoapySDR**
- Компилятор C / CMake
- Python (matplotlib) — для построения графика

Подключение устройства: **USB** (`uri = "usb:"`).

---

### 3. Параметры настройки SDR

---------------------------------------------
| Параметр              | Значение          |
|-----------------------|-------------------|
| Driver                | `plutosdr`        |
| URI                   | `usb:`            |
| Sample Rate (RX/TX)   | `1e6` (1 МГц)     |
| Carrier Frequency     | `800e6` (800 МГц) |
| Format                | `SOAPY_SDR_CS16`  |
| Gain RX               | `10.0`            |
| Gain TX               | `-90.0`           |
| timestamp_every       | `1920`            |
| loopback              | `0`               |
---------------------------------------------
