## 1. GNU Radio. Построение радио-приёмника

### 1. Цель работы

Ознакомиться с инструментарием **GNU Radio**, научиться строить конфигурацию программного FM-радиоприёмника с использованием SDR-устройства **ADALM-Pluto (PlutoSDR)** и выполнить приём реальной FM-радиостанции.

В ходе работы необходимо было:

- подключить SDR-приёмник ADALM-Pluto к GNU Radio;
- исследовать спектр принимаемых радиосигналов;
- найти частоту действующей FM-радиостанции;
- выделить необходимый сигнал с помощью фильтра;
- выполнить FM-демодуляцию;
- получить и воспроизвести аудиосигнал.

---

### 2. Используемое оборудование и программное обеспечение

- SDR-приёмник **ADALM-Pluto**
- GNU Radio Companion
- операционная система Windows
- акустическая система / наушники компьютера

Для подключения PlutoSDR использовался:

```text
IIO Context URI = 192.168.3.1
```

---

### 3. Описание схемы

В GNU Radio Companion была собрана схема приёмника широковещательного FM-сигнала.

#### Основные блоки

| Блок | Назначение | Основные параметры |
|---|---|---|
| **PlutoSDR Source** | Приём IQ-сигнала с SDR-устройства | LO Frequency = 99 МГц; Sample Rate = 2.4 МГц; RF Bandwidth = 20 МГц |
| **Variable** | Задание частоты дискретизации | `samp_rate = 2.4M` |
| **QT GUI Range** | Подстройка центральной частоты | `tune`; 80–110 МГц; шаг 100 кГц; начальное значение 99 МГц |
| **Low Pass Filter** | Фильтрация и уменьшение частоты дискретизации | Decimation = 5; Cutoff Freq = 100 кГц; Transition Width = 50 кГц; Window = Blackman |
| **QT GUI Frequency Sink** | Отображение спектра | FFT Size = 1024 |
| **WBFM Receive** | Демодуляция широкополосного FM-сигнала | Quadrature Rate = 480 кГц; Audio Decimation = 10 |
| **QT GUI Time Sink** | Отображение сигнала во временной области | Number of Points = 1.024k; Sample Rate = 480 кГц |
| **Audio Sink** | Воспроизведение аудиосигнала | Sample Rate = 48 кГц |

Полная схема обработки сигнала:

```text
PlutoSDR Source
       │
       ├──────────────► QT GUI Frequency Sink
       │                широкий спектр, 2.4 МГц
       │
       ▼
Low Pass Filter
Decimation = 5
Cutoff = 100 кГц
       │
       ├──────────────► QT GUI Frequency Sink
       │                полоса 480 кГц
       │
       ├──────────────► QT GUI Time Sink
       │
       ▼
WBFM Receive
Quadrature Rate = 480 кГц
Audio Decimation = 10
       │
       ├──────────────► QT GUI Frequency Sink
       │                спектр аудиосигнала
       │
       ▼
Audio Sink
Sample Rate = 48 кГц
```

### 4. Построение и настройка приёмника

#### 4.1. Настройка PlutoSDR Source

В качестве источника радиосигнала использовался блок **PlutoSDR Source**.

Основные параметры блока:

| Параметр | Значение |
|---|---:|
| IIO Context URI | `192.168.3.1` |
| LO Frequency | `99 MHz` |
| Sample Rate | `2.4 MHz` |
| Buffer Size | `32.768k` |
| Quadrature | `True` |
| RF DC Correction | `True` |
| BB DC Correction | `True` |
| Gain Mode | `Slow Attack` |
| Filter Configuration | `Auto` |
| RF Bandwidth | `20 MHz` |

Входная частота дискретизации составила **2.4 МГц**, что позволило наблюдать широкий участок радиочастотного диапазона.

---

#### 4.2. Настройка частоты

Для подстройки частоты использовался блок **QT GUI Range**.

Параметры:

| Параметр | Значение |
|---|---:|
| ID | `tune` |
| Default Value | `99 MHz` |
| Start | `80 MHz` |
| Stop | `110 MHz` |
| Step | `100 kHz` |

С помощью данного блока можно было изменять частоту настройки приёмника и исследовать FM-диапазон.

В результате поиска была найдена действующая FM-радиостанция на частоте:

**99.1 МГц**

---

#### 4.3. Анализ спектра

Для наблюдения спектра использовался блок **QT GUI Frequency Sink**.

На входе схемы применялся анализатор со следующими параметрами:

- FFT Size = `1024`;
- Center Frequency = `101.1 MHz`;
- Bandwidth = `2.4 MHz`.

При изменении частоты настройки на спектре наблюдались участки с повышенной мощностью, соответствующие радиосигналам FM-станций.

При настройке на найденную станцию **99.1 МГц** наблюдался характерный спектральный участок FM-сигнала шириной порядка 200 кГц.

---

#### 4.4. Фильтрация сигнала

Для выделения полезного FM-сигнала использовался **Low Pass Filter**.

Параметры:

| Параметр | Значение |
|---|---:|
| Decimation | `5` |
| Gain | `1` |
| Sample Rate | `2.4 MHz` |
| Cutoff Freq | `100 kHz` |
| Transition Width | `50 kHz` |
| Window | `Blackman` |

Фильтр ограничивает полосу принимаемого сигнала и уменьшает влияние сигналов, находящихся за пределами выбранной полосы.

Одновременно выполнялась децимация в 5 раз.

Исходная частота дискретизации:

\[
f_s = 2.4\text{ МГц}
\]

После децимации:

\[
f_{s2} = \frac{2.4}{5} = 0.48\text{ МГц} = 480\text{ кГц}
\]

Таким образом, после `Low Pass Filter` частота дискретизации составила **480 кГц**.

---

#### 4.5. FM-демодуляция

Для демодуляции использовался блок **WBFM Receive**.

Параметры:

| Параметр | Значение |
|---|---:|
| Quadrature Rate | `480 kHz` |
| Audio Decimation | `10` |

На вход блока поступал отфильтрованный сигнал с частотой дискретизации **480 кГц**.

После демодуляции и децимации в 10 раз:

\[
f_{audio} = \frac{480}{10} = 48\text{ кГц}
\]

Таким образом, на выходе `WBFM Receive` формировался аудиосигнал с частотой дискретизации **48 кГц**.

---

#### 4.6. Контроль сигнала во временной области

Для наблюдения сигнала во временной области использовался **QT GUI Time Sink**.

Параметры блока:

- Number of Points = `1.024k`;
- Sample Rate = `480 kHz`;
- Autoscale = `No`.

С помощью данного блока контролировался сигнал после фильтрации и перед дальнейшей обработкой.

---

#### 4.7. Воспроизведение аудиосигнала

Последним этапом обработки являлась передача демодулированного сигнала в блок **Audio Sink**.

Параметр:

```text
Sample Rate = 48 kHz
```

После запуска схемы полученный FM-сигнал демодулировался, преобразовывался в аудиопоток и выводился через аудиоустройство компьютера.

В результате удалось получить разборчивый звук принимаемой радиостанции **99.1 МГц**.

---

### 5. Результаты работы

#### 5.1. Найденная радиостанция

С помощью блока `QT GUI Range` выполнялось изменение частоты настройки в диапазоне **80–110 МГц**.

В процессе поиска была обнаружена и принята радиостанция на частоте:

**99.1 МГц**

На спектре наблюдался характерный участок FM-сигнала, после чего частота была зафиксирована для дальнейшей обработки.

---

#### 5.2. Спектральная обработка

На входе схемы сигнал имел частоту дискретизации **2.4 МГц**.

После прохождения через `Low Pass Filter` с децимацией `5` частота дискретизации уменьшилась до:

**480 кГц**

Это значение использовалось в качестве `Quadrature Rate` блока `WBFM Receive`.

После FM-демодуляции и децимации `10` получался аудиосигнал:

**48 кГц**

Таким образом, последовательность изменения частоты дискретизации была следующей:

```text
2.4 МГц
   ↓ Decimation = 5
480 кГц
   ↓ Audio Decimation = 10
48 кГц
```

---

#### 5.3. Аудиовоспроизведение

После настройки частоты и параметров обработки на выходе `Audio Sink` появился разборчивый аудиосигнал радиостанции.

Работа схемы подтвердила корректность последовательности:

```text
приём → фильтрация → децимация → FM-демодуляция → аудио
```

### 6. Вывод

В ходе практической работы была собрана и запущена схема программного FM-радиоприёмника в среде **GNU Radio Companion** с использованием **ADALM-Pluto SDR**.

Были изучены основные этапы обработки радиосигнала: приём IQ-сигнала, анализ спектра, фильтрация, децимация, FM-демодуляция и вывод аудио.

В результате была найдена и принята реальная FM-радиостанция на частоте **99.1 МГц**. Исходная частота дискретизации составляла **2.4 МГц**, после фильтрации и децимации — **480 кГц**, а после FM-демодуляции — **48 кГц**.

Полученный аудиосигнал был передан на `Audio Sink` и воспроизведён через аудиоустройство компьютера.

Таким образом, поставленная цель работы была выполнена: с помощью графического конструктора GNU Radio была создана работоспособная схема FM-радиоприёмника для приёма и обработки реального радиосигнала.
