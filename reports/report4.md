### 1. Цель работы

Цель данной работы - освоение взаимодействия с программно-определяемым радиомодулем **ADALM-Pluto** через библиотеку **SoapySDR**. Задачи работы:

- подключить и сконфигурировать ADALM-Pluto;

- выполнить настройку параметров приёмника и передатчика;
- организовать приём и передачу IQ-данных;
- сохранить принятые сэмплы в файл `.pcm`;
- визуализировать сохранённые данные с помощью Python.

### 3. Описание программы

Программа `main.cpp` обеспечивает работу с ADALM-Pluto через SoapySDR. Режим работы задаётся двумя аргументами:

```bash
./main <rx> <tx>
```

где:

- `rx = 1` - включить приём, `0` - отключить;
- `tx = 1` - включить передачу, `0` - отключить.

Примеры запуска:

```bash
./main 1 0   # только приём
./main 0 1   # только передача
./main 1 1   # приём и передача одновременно
```

#### 3.1. Инициализация устройства

| Ключ              | Значение   | Назначение                          |
|-------------------|------------|-------------------------------------|
| `driver`          | `plutosdr` | драйвер PlutoSDR                    |
| `uri`             | `usb:`     | подключение по USB                  |
| `direct`          | `1`        | прямой доступ через DMA             |
| `timestamp_every` | `1920`     | период выдачи временных меток       |
| `loopback`        | `0`        | внутренняя петля отключена          |

#### 3.2. Настройка параметров RX и TX

Для активного направления задаются следующие параметры:

```c
double sample_rate = 1e6;      // 1 MSPS
double carrier_freq = 800e6;   // 800 МГц
```

- частота дискретизации - **1 MSPS**;
- несущая частота - **800 МГц**;
- усиление RX - **10.0 дБ**;
- усиление TX - **-90.0 дБ** (близко к минимальному значению).

#### 3.3. Создание потоков

Потоки создаются в формате `SOAPY_SDR_CS16` (комплексные знаковые 16-битные сэмплы):

```c
rxStream = SoapySDRDevice_setupStream(sdr, SOAPY_SDR_RX, SOAPY_SDR_CS16,
                                      channels, channel_count, NULL);
SoapySDRDevice_activateStream(sdr, rxStream, 0, 0, 0);
```

Аналогично выполняется настройка TX-потока. Используется один канал (индекс `0`).

#### 3.4. Буферы и MTU

Размер буфера определяется вызовом `SoapySDRDevice_getStreamMTU`. Память выделяется динамически:

```c
rx_buffer = (int16_t*)malloc(sizeof(int16_t) * 2 * rx_mtu);
tx_buff   = (int16_t*)malloc(sizeof(int16_t) * 2 * tx_mtu);
```

Множитель `2` необходим, так как каждый сэмпл содержит две компоненты — I и Q.

#### 3.5. Основной цикл приёма

В цикле (40 итераций) вызывается `SoapySDRDevice_readStream`. Полученные данные записываются в файл `rxdata.pcm` в бинарном формате. В консоль выводится информация вида:

```text
Buffer N | Samples: S | Flags: F | Time: T | Diff: D нс
```

где `Time` — временная метка первого сэмпла буфера, а `Diff` — разница относительно предыдущей метки.

#### 3.6. Передача с временной меткой

На третьей итерации формируется тестовый сигнал и отправляется с привязкой ко времени:

```c
long long tx_time = timeNs + (4 * 1000 * 1000); // +4 мс
```

В начало TX-буфера записывается служебный заголовок:

- маркеры `0xffff` в позициях 0–1 и 10–11;
- 8 байт значения `tx_time` в позициях 2–9 (побайтовая запись со сдвигом `<< 4`).

Передача выполняется с флагом `SOAPY_SDR_HAS_TIME`:

```c
flags = SOAPY_SDR_HAS_TIME;
SoapySDRDevice_writeStream(sdr, txStream, tx_buffs, tx_mtu,
                           &flags, tx_time, timeoutUs);
```

#### 3.7. Завершение работы

Ресурсы освобождаются в обратном порядке:

1. `fclose(file)`;
2. `SoapySDRDevice_deactivateStream` и `closeStream` для RX и TX;
3. `free(rx_buffer)`, `free(tx_buff)`;
4. `SoapySDRDevice_unmake(sdr)`.
